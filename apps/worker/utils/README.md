# Worker Utils

Папка для общих утилит worker'а. Сюда стоит выносить только код, который не принадлежит конкретному runner, model adapter или API client.

## Что здесь уместно

- работа с временными файлами;
- общие retry/backoff helpers;
- логирование и correlation ids;
- image/file helpers без привязки к provider'у;
- функции нормализации ошибок;
- небольшие pure helpers.

## Правила

- Не превращайте `utils` в свалку бизнес-логики.
- Если helper нужен coordinator и worker одновременно, перенесите его в `apps/shared`.
- Утилиты должны иметь понятные тесты, потому что ими будут пользоваться разные runner'ы.
