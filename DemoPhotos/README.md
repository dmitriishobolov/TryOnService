# DemoPhotos

Папка для демонстрационных фотографий, которые можно использовать при ручной проверке сценариев примерки во время разработки.

## Правила

- Не добавляйте сюда реальные клиентские данные без явного разрешения.
- Не храните секреты, export'ы из production или приватные материалы.
- Для автоматических тестов лучше использовать отдельные маленькие fixtures внутри соответствующего тестового пакета.
- Если фотографии становятся большими, лучше вынести их во внешнее хранилище или описать способ получения в документации.
